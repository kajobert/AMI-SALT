# AMI-SALT

> **Trust instead of Authority.**

AMI-SALT is the public trust, contribution and sustainability layer of the AMI ecosystem.

SALT is intended to represent **earned, evidence-backed trust and contribution**. Financial support is tracked separately as transparent infrastructure backing: money can fund AMI's compute, inference, storage and development runway, but it does **not buy SALT trust**.

Initial design goals:

- evidence-linked contribution and trust records;
- deterministic, auditable ledger state;
- transparent support and infrastructure runway accounting;
- opt-in supporter recognition without pay-to-win reputation;
- interoperability with AMI-Protocol and AMI-Knowledge-Core;
- public development with private credentials and personal data kept out of the repository.
